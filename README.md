# 🌐 Static Portfolio Website on Amazon S3 using Terraform

## Overview

This project demonstrates how to deploy a static portfolio website on Amazon S3 using Terraform.

The infrastructure is created using Infrastructure as Code (IaC).

## Technologies

- Terraform
- AWS
- Amazon S3
- HTML
- CSS
- JavaScript

## Features

- Create an S3 Bucket
- Enable Static Website Hosting
- Upload website files
- Deploy using Terraform

## Project Structure

```
.
├── images/
├── index.html
├── style.css
├── script.js
├── main.tf
└── README.md
```

## Deployment

```bash
terraform init
terraform validate
terraform plan
terraform apply
```
